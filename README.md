# «Гаечный ключ» — автосервис

Учебный проект по заданию 2, вариант 2 («Гаечный ключ», автосервис).

## Структура

```text
gaechniy-klyuch/
├── index.html
├── register.html
├── login.html
├── orders.html
├── create.html
├── admin.html
├── style.css
├── img/
└── README.md
```

## Запуск

Откройте `index.html` в браузере

## Что реализовано

- Шесть страниц по заданию: главная, регистрация, вход, мои заявки, новая заявка, панель администратора.
- Единые шапка и подвал; у текущей страницы активная ссылка.
- Классы в стиле БЭМ, общие стили находятся в `css/style.css`.
- Семантические теги, подписи полей, типы и ограничения HTML-форм.
- Адаптивная вёрстка для узких экранов; таблица администратора прокручивается по горизонтали.
- Демонстрационные карточки заявок с четырьмя статусами.

## Важно

Это только этап вёрстки. Формы не отправляют данные на сервер, авторизация, фильтрация и сохранение статуса пока не работают — серверную логику по заданию подключают позднее. Данные на страницах заявок демонстрационные.
